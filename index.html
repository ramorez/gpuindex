Methodology. GPUI is an equal-weight price index of published on-demand cloud GPU list prices, expressed against a base value of 100 set on 2026-08-22. Each constituent's daily price is the median of independent provider list rates; the index is the arithmetic mean of price-relatives (constituent ÷ its day-1 base price). Only constituents observed from two or more independent published sources are included. Prices are refreshed daily at 08:00 (UAE) from live public list pages.

GPUs tracked. The core index is a fixed equal-weight basket of the four datacenter workhorses — H100, H200, A100, B200 — each of which must clear a gate of ≥ 2 independent published on-demand sources on a given day. Inference/edge GPUs L40S, B300, RTX 4090, RTX 5090 are tracked as reference, outside the core basket by design (some, e.g. L40S, also carry multiple sources but are intentionally not indexed). The exact reason a reference GPU is excluded is its tier, not merely its source count. Actual provider prices are not published.
